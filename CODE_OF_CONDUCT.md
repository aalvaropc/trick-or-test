# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, give and accept constructive feedback, and focus on what is best for the project and the people using it. Harassment and personal attacks are not tolerated.

## Reporting

Report unacceptable behaviour privately to the maintainer, [@aalvaropc](https://github.com/aalvaropc), through GitHub. Reports are handled confidentially, and the enforcement guidelines of the Contributor Covenant apply.
